# Documentación

**Los cuatro archivos de la raíz de `docs/` tienen la ruta que fija la guía; no se mueven ni se renombran.**

## Entregables con ruta fija (los califica la guía)
| Archivo | Entregable | Quién escribe |
|---|---|---|
| [`bitacora_ia.md`](bitacora_ia.md) | E3 · Bitácora de IA | Cada integrante agrega **sus** entradas, con su nombre en "Autor" |
| [`contribucion.md`](contribucion.md) | E4 · Bitácora de contribución (una tabla por hito) | Cada integrante llena **su** fila |
| [`preguntas_y_reportes.md`](preguntas_y_reportes.md) | E6 · Preguntas y reportes | Quien hizo la pregunta o encontró el problema |
| [`seguridad.md`](seguridad.md) | Documento de seguridad y datos personales | Equipo |

## Carpetas
| Carpeta | Contenido |
|---|---|
| [`ESTADO.md`](ESTADO.md) | Estado actual del proyecto (empieza aquí) |
| [`requisitos/`](requisitos/) | Historias de usuario (HU-01 a HU-17) con criterios de aceptación |
| [`tecnico/`](tecnico/) | [Arquitectura](tecnico/arquitectura.md), [modelo de datos](tecnico/modelo_datos.md), [pruebas](tecnico/pruebas.md), puesta en marcha de la org (`setup_org.md`) y análisis de código (`code_analyzer.md`) |
| [`prompts/`](prompts/README.md) | Prompts estructurados, **una carpeta por integrante**: `dilian/`, `jimena/` |
| [`equipo/`](equipo/) | **Un archivo por integrante** con sus tareas, evidencia y horas (de ahí sale su fila de `contribucion.md`), y el prompt para el agente de IA de cada integrante |
